# Урок 3-2

Отдельная версия интерактивного лендинга «Тактильный интерфейс» для дальнейшей доработки.

## Публикация

Сайт размещён с помощью GitHub Pages из ветки `main`.

## Файлы

- `index.html` — самостоятельная страница без внешних зависимостей.
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages.
