# Урок 3-2

Отдельная учебная трёхэкранная версия сайта Ксении Богатовой. Основной сайт развивается в другом репозитории и не зависит от этого проекта.

## Открыть

[GitHub Pages](https://bogatovaprof-hub.github.io/urok-3-2/)

## Три экрана

1. Первый экран с позиционированием и портретом.
2. Экран с видео о подходе.
3. Экран обратной связи с локальной подготовкой сообщения.

Форма учебная: она не передаёт данные в сеть и не имитирует успешную отправку. Подготовленный текст можно проверить и скопировать.

## Технологии

- HTML5;
- CSS3;
- vanilla JavaScript;
- локальные изображения и видео;
- без сборки, внешних библиотек, аналитики и сетевых зависимостей.

GitHub Pages публикует сайт из корня ветки `main`.
